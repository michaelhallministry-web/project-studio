Behind the connection

Built for studio-to-studio collaboration.

TrackLab uses Cubase Pro and Steinberg VST Connect for compatible remote sessions. Producers and engineers with a suitable host setup can direct keyboard performances remotely. Musicians may also connect through VST Connect Performer when the host and session configuration support it.

Before a session, we'll confirm the host and performer configuration, audio and MIDI routing, monitoring, connection quality, recording format, and scheduling.

Remote keyboard and MIDI contributions are arranged directly with the studio or producer. Session timing and technical compatibility are confirmed together before recording.
