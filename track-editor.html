1. Edit the titles above and select Copy updated titles.
2. Open the title file in GitHub.
3. Replace its entire contents with the copied text.
4. Select Commit changes. The music player will update automatically after deployment.

Never rename MP3 files in GitHub's text editor. If you need to change audio, upload the actual MP3 file.
